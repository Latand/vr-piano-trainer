# Sounds in this folder

The song voice of the trainer (docs/piano-audio-design.md §5): 21 recordings of a grand piano, one
every minor third from C2 to C7, each played at its own pitch and a semitone either side, so the
61 keys are covered. They are the subset of the **Salamander Grand Piano** (a Yamaha C5, recorded
and released by Alexander Holm) that the Tone.js project publishes as MP3 in its `audio`
repository, downloaded unchanged from one pinned commit and renamed only by folder.

- **Source:** https://github.com/Tonejs/audio/tree/efd8296360f9526e379bfbe5c1698ff54d6a1d34/salamander
  (commit `efd8296`, 2020-05-27), files `<name>.mp3`.
- **Licence of the set:** CC BY 3.0, as the README shipped with the files states ("Licence: CC-by
  http://creativecommons.org/licenses/by/3.0/", author Alexander Holm). The author's page
  (https://rytmenpinne.wordpress.com/sounds-and-such/salamander-grandpiano/) adds "As of 4.3.2022,
  this is now public domain!". CC BY 3.0 is recorded below: it holds either way, and its credit is
  given here and in the README's «Пісні».
- **Credit (CC BY):** "Salamander Grand Piano" by Alexander Holm, CC BY 3.0
  (https://creativecommons.org/licenses/by/3.0/); MP3 subset by the Tone.js project.
- **Checked:** README and file list read at the commit, the author's page read, 2026-10-23.

`tools/check-licences.mjs` checks every hash below against the bytes (`node
piano/tools/check-licences.mjs`, CTest `piano_licence_check`).
